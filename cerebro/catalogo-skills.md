# Catálogo de skills

Qué skill usar para cada tipo de tarea. Si no está aquí, usa `find-skills`.

## Skills de este repo (propias)
| Skill | Para qué |
|---|---|
| `cerebro` | Leer y guardar memoria (preferencias, decisiones, aprendizajes) |
| `crear-skill` | Convertir una tarea repetida en una skill nueva |
| `aplicar-skills` | Instalar en un proyecto solo las skills que le sirven |
| `find-skills` | Buscar e instalar skills del ecosistema (skills.sh) |

## Skills recomendadas por tipo de proyecto
Instálalas con `npx skills add <paquete>` (revisa siempre antes de instalar).

| Tipo de proyecto | Skills sugeridas | Paquete |
|---|---|---|
| Web con React / Next.js | react-best-practices, web-design-guidelines | `vercel-labs/agent-skills` |
| Diseño de interfaz | frontend-design | `anthropics/skills` |
| Documentos (Word, PDF, Excel, PowerPoint) | docx, pdf, xlsx, pptx | `anthropics/skills` |
| Crear skills propias | skill-creator | `anthropics/skills` |
| Proceso de desarrollo (planes, TDD, debugging) | superpowers | `obra/superpowers` |
